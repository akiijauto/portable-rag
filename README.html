ローカルRAG 導入手順

HTML 文書 5,000件を、インストール不要・ローカル完結で検索し、AI に渡しやすい形で出力するツールです。

1. 必要なもの

  • Python 3.9 以上（業務PCに入っている Python で可）
  • このフォルダ一式（Google ドライブで配布可）
  • 意味検索を使う場合のみ：pip install -r requirements-optional.txt（sentence-transformers, numpy）

2. 配置

38_local_rag/
├─ build_index.py      索引の作成・差分更新
├─ search.py           コマンドライン検索
├─ rag_app.py          ブラウザ UI（http://127.0.0.1:8765）
├─ build_index.bat     Windows 用ダブルクリック起動
├─ run_search.bat      Windows 用ダブルクリック起動
├─ config.json         設定（検索対象フォルダなど）
├─ rag/                本体モジュール
├─ sample_docs/        動作確認用サンプル
├─ tests/              機能テスト
└─ index/              索引（自動生成。共有・コミットしない）

3. 設定（config.json）

{
  "source_dirs": ["G:/マイドライブ/業務文書"],   ← 検索対象フォルダ（複数可）
  "index_dir": "./index",                        ← 索引の保存先
  "chunk_size": 600,
  "chunk_overlap": 120,
  "embedding_model": "intfloat/multilingual-e5-small",
  "use_embeddings": "auto",                      ← auto / true / false
  "top_k": 8,
  "web_port": 8765
}

Windows のパスは / 区切りか \\ で書きます。索引は機密を含むので、共有ドライブではなくローカル（例 C:/Users/名前/rag_index）に置くことを推奨します。

4. 使い方

4-1. 索引を作る

python build_index.py          # 差分更新（2回目以降は変更分だけ）
python build_index.py --full   # 全件作り直し（設定変更後など）

4-2. ブラウザで検索する

python rag_app.py

ブラウザが自動で開きます。検索語を入れて「検索」。タブで「閲覧 / Gemini貼付用 / スプレッドシート用(TSV)」を切り替え、「コピー」でクリップボードへ。「差分インデックス更新」で新しいファイルを取り込みます。

4-3. コマンドラインで検索する

python search.py "返品 送料 負担" --format prompt              # Gemini に貼る文章を表示
python search.py "返品 送料 負担" --format tsv --out result.tsv  # スプレッドシート用
python search.py "返品 送料 負担" --format html --out result.html
python search.py "返品 送料 負担" --mode bm25 --top 20          # キーワードのみ / 件数変更

4-4. 系列まとめ（中間ファイル作成）

NotebookLM は最大 300 ソース、Gemini チャットは最大 10 ファイルまでしか渡せません。bundle.py は文書を「系列」ごとに集め、上限に収まる大きなファイルと、Gemini に要約させるための依頼文を作ります。

python bundle.py                                   # 対話メニュー（bundle.bat でも可）
python bundle.py --by folder                       # サブフォルダごと
python bundle.py --by "name:^(?P<series>[^_]+)_"    # ファイル名の先頭〜'_' を系列名に
python bundle.py --by "field:顧客名"                # 本文の「顧客名: ○○」の値ごと
python bundle.py --by "search:返品 送料" --top 50   # 検索上位50件を1系列に
python bundle.py --by folder --mode summary --compact   # 要約依頼のみ・定型行を除去
出力（bundles/<系列>/）内容
notebooklm/*.txt本文を連結し 30万文字ごとに分割（最大300）。NotebookLM のソースに追加
gemini/*.txt12万文字ごとに分割（最大10）。Gemini チャットに添付
summary_prompt/*.txtGemini に貼る要約依頼文。返ってきた要約を <系列>_要約.md に貼って保管
index.html系列ごとの件数・分割数の一覧。⚠ は上限で打ち切り

要約 .md を検索対象フォルダに置けば RAG からも検索できます（extensions に .md を含めています）。

5. AI への渡し方

使い方手順
ブラウザの Gemini「Gemini貼付用」をコピーして貼り付ける。質問と根拠資料がセットになった文章が入る
スプレッドシートの AI 関数TSV をコピーしてシートに貼る（またはファイル→インポート）。=AI("この資料を根拠に返品時の送料負担を答えて", A2:E9) のように範囲参照する
人が探す「閲覧」タブ。ファイル名リンクで元の HTML が開く

6. 意味検索（任意）

  1. pip install -r requirements-optional.txt
  2. python build_index.py を再実行（不足分のベクトルだけ追加される）
  3. 初回はモデル（約120MB）がダウンロードされます。オフライン PC では、ネットに繋がる PC の ~/.cache/huggingface フォルダをドライブ経由でコピーすれば動きます

UI の「ハイブリッド」がキーワード＋意味検索の統合、「意味検索」が単独です。効果が薄ければ use_embeddings を false にすれば以前の動作に戻ります。

7. テスト

python tests/test_rag.py

抽出・分割・検索・差分更新・出力形式の10項目を確認します。ブラウザ操作テストは Playwright で実施済み（振り返り.html 参照）。

8. よくある質問

症状対処
文字化けするcp932/utf-8 は自動判定。それ以外は rag/html_extract.py の候補に文字コードを追加
ポート 8765 が使えないconfig.json の web_port を変える
検索結果が多すぎる/少なすぎるUI の件数欄、または --top。1文書あたり最大2件の制限は rag/search.py
索引が壊れたindex/ フォルダを削除して --full で作り直す（削除は利用者が実施）
