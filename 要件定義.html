要件定義：ローカル完結 RAG 検索システム

作成日 2026-09-02　対象 projects/38_local_rag

1. 背景と目的

業務用のノートPCには制限があり、外部 API は使えず、共有手段は Google ドライブのみ。手元にある約5,000件の HTML 文書（テンプレート型の業務文書と、非定型の問い合わせ回答メール）を AI が参照しやすい形で検索・出力できる仕組みが必要。

目的は「検索した根拠をそのまま AI（ブラウザの Gemini、スプレッドシートの AI 関数）に渡せる」こと。AI 本体はこのソフトに含めず、検索と整形に専念する。

2. 前提条件（ヒアリング結果）

項目内容
実行環境業務用のノートPC。Python 本体あり、pip でのライブラリ導入は可。管理者権限インストールは不可
データHTML 約5,000件、主に日本語、機密情報を含む、定期的に追加・更新される
参照する AI①スプレッドシートの AI 関数（セル範囲参照）②ブラウザの Gemini に貼り付け ③人が過去の類似案件として検索
検索方式キーワード検索を基本とし、意味検索（ベクトル）も試せること
共有手段Google ドライブ（ローカル同期フォルダ）のみ

3. 機能要件

ID要件実装
F-1指定フォルダ配下の HTML/TXT/MD を再帰的に読み込み、本文とタイトルを抽出するrag/html_extract.py（script/style 除去、cp932/utf-8 自動判定）
F-2差分更新。追加・更新・削除されたファイルだけを再インデックスするrag/indexer.py（mtime+size+sha1 で判定）
F-3日本語のキーワード検索（形態素解析器なし）文字 bigram + 英数字単語、BM25、完全一致フレーズ加点
F-4意味検索（任意）。ライブラリが無ければ自動で無効rag/embed.py、multilingual-e5-small、RRF でハイブリッド統合
F-5出力形式：TSV（スプレッドシート）/ 貼付用プロンプト（Gemini）/ HTML（閲覧）/ JSONrag/formats.py
F-6ブラウザから使えるローカル UI（検索・形式切替・コピー・差分更新ボタン）rag_app.py（標準ライブラリ http.server、127.0.0.1 のみ待受）
F-7コマンドラインからも検索でき、ファイルへ書き出せるsearch.py --format tsv --out result.tsv
F-8同一文書からの結果は最大2チャンクに制限し、複数文書を並べるrag/search.py

4. 非機能要件

項目要件確認結果
インストール不要標準ライブラリのみで全機能（意味検索を除く）が動くnumpy/bs4 の無い環境でテスト合格
ローカル完結外部通信ゼロ。Web UI は localhost のみコードに外部 URL への通信なし（モデル取得時を除く）
性能5,000件を数分以内に索引化、検索1秒以内5,000件 17,627チャンク：構築 33.5秒、検索 0.4秒、差分更新 0.1秒
可搬性索引は SQLite ファイル1個。ドライブ経由で別PCへ持ち運べるindex/rag.sqlite
安全性索引ファイルは機密を含むため git 管理外.gitignore で index/ を除外

5. 構成

Google ドライブ同期フォルダ（HTML 5000件）
      │  build_index.py（差分読込）
      ▼
index/rag.sqlite（文書・チャンク・転置索引・ベクトル）
      │  search.py / rag_app.py
      ▼
BM25 ─┬─ RRF 統合 ─→ 上位 K 件 ─→ TSV / プロンプト / HTML / JSON
ベクトル（任意）┘                       │
                     スプレッドシート AI 関数 ／ ブラウザ Gemini ／ 人の閲覧

6. スコープ外

  • AI による回答生成そのもの（外部 API が使えないため）
  • Google ドライブ API との連携（ローカル同期フォルダを参照する）
  • OCR、PDF、Office 文書の読み込み（将来拡張候補）

7. 検討した代替案

案採否理由
形態素解析器（MeCab/Sudachi）不採用辞書のインストールが必要。bigram で 5,000件規模なら実用精度
Whoosh / rank_bm25 等の外部ライブラリ不採用pip 不可の PC でも動くよう標準ライブラリで自作
Flask Web UI不採用依存を増やさないため http.server を使用
ベクトル DB（Chroma 等）不採用17,000 ベクトル程度なら SQLite + 総当たりで十分
